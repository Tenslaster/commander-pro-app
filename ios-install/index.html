Commander PRO

Install on iPhone with a normal free Apple ID (no $99 developer account).

Important: Apple does not let a free Apple ID install an unsigned IPA from Safari alone. You sign it on the phone with SideStore (free, 7‑day refresh). This page gives you the IPA download + steps.
Download CommanderPro.ipa

1) Install SideStore (once)

  1. On iPhone Safari open https://sidestore.io
  2. Follow their install guide (pairing / SideInstaller methods change over time)
  3. When SideStore is installed, open it and sign in with your normal Apple ID
  4. Settings → General → VPN & Device Management → trust the developer profile if asked
SideStore uses Apple’s free personal signing (same as a free “developer” identity). Apps expire about every 7 days — open SideStore and Refresh (on Wi‑Fi).

2) Install Commander PRO

  1. Tap Download CommanderPro.ipa above (Safari / Files)
  2. Open SideStore → My Apps → + / install IPA
  3. Pick CommanderPro.ipa from Downloads/Files
  4. Wait for SideStore to sign + install
  5. Open Commander PRO from the home screen

3) If install fails

  • Enable Wi‑Fi (SideStore refresh/install often needs network)
  • Apple ID: use an app‑specific password if you have 2FA and SideStore asks
  • You can only have a few free sideloaded apps at once — delete unused ones
  • Wrong iOS version / SideStore out of date — reinstall SideStore from sidestore.io
